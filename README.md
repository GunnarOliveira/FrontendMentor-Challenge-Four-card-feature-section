## 📜 About the Project

This project is a solution to the **[Four card feature section challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/four-card-feature-section-we210A356)**. Challenge by **Frontend Mentor**. Frontend Mentor challenges help developers improve their coding skills by building realistic UI components.

### The Challenge

Users should be able to:
* View the optimal layout for the site depending on their device's screen size (Mobile & Desktop).
* See hover states for interactive elements.

---

## 🛠️ Built With

* **HTML5**: Semantic elements (`<header>`, `<main>`, `<section>`, `<article>`) for clear structure and accessibility.
* **CSS3**: Custom properties (variables), typography, and custom top borders for each feature card.
* **CSS Grid & Flexbox**: Used to build the multi-column layout on desktop and single-column stacked view on mobile.
* **Mobile-First Workflow**: Designed to adapt fluidly across various screen sizes.

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/GunnarOliveira/FrontendMentor-Challenge-Four-card-feature-section.git](https://github.com/GunnarOliveira/FrontendMentor-Challenge-Four-card-feature-section.git)
   ```

2. **Navigate to the project folder:**
   ```bash
   cd FrontendMentor-Challenge-Four-card-feature-section
   ```

3. **Open `index.html`** in your web browser (or use the *Live Server* extension in VS Code).
